How it works

  1. Split. The model is broken into parts. A STEP file keeps its part names. Identical parts, like four wheels, get one drawing with the right quantity.
  2. Project. Each part is drawn in front, top and side views plus an isometric view. Hidden edges are dashed.
  3. Measure. Overall dimensions are added, and every round hole goes into a hole table with its position, diameter, depth or THRU, counterbore and bolt circle.
  4. Export. Download each sheet as PDF, DXF or SVG. Flat plates also get a 1:1 DXF outline for a laser cutter or CNC router.

Before you send it to a shop

  • Fill in the material and tolerance boxes. They print in every title block.
  • Thread callouts, surface finish and dimensions for slots or pockets are not added automatically. Add them in the DXF.
  • STL files have no part names and no true circles. STEP gives the best results.
  • If an STL fuses several parts into one body, export the parts separately first.
  • Hole sizes ending in "?" are guesses, such as M3 clearance. Confirm them.

Python version

For batch work or very large assemblies, the same converter runs from the command line using CadQuery and OpenCascade, with exact geometry.

pip install -r python/requirements.txt
python python/step2drawings.py robot.step -o drawings
python python/stl2drawings.py model.stl -o drawings
